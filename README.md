# Desafio 02 – Busca de Perfil no GitHub

Projeto desenvolvido para o **Avanti Innovation Challenge – Innovation Class 19**.

Aplicação em React que busca perfis do GitHub e exibe as informações do usuário conforme o layout do Figma.

## Requisitos

- [ ] Campo de busca para informar o nome de um perfil do GitHub
- [ ] Ao clicar no botão de busca, consumir a API do GitHub
- [ ] Exibir nome, foto de perfil e bio do usuário
- [ ] Exibir mensagem de erro caso o perfil não seja encontrado
- [ ] Estilização seguindo o design do Figma
- [ ] Opcional: efeitos visuais e loading durante a requisição

## Tecnologias

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- CSS

## Como executar

Requer [Node.js](https://nodejs.org/) 20.19 ou superior.

```bash
npm install
npm run dev
```
